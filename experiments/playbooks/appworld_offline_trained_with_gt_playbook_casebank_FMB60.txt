[shr-00009] Always verify the data schema of each API endpoint before assuming data availability
- Never assume that metrics like play_count, like_count, or other analytics are available in a library or listing API. Always use the detailed song endpoint (`show_song`) to retrieve such metrics, as they are not included in basic library listings.
[shr-00012] Always verify the data schema of listing APIs before assuming metadata availability
- Before assuming that a listing API (e.g., album_library, playlist_library) contains song titles, play_count, or other metadata, always consult the API documentation using `apis.api_docs.show_api_doc(app_name='spotify', api_name='show_song')`. Listing APIs only return song IDs; full song details (title, play_count, like_count) are only available via the detailed `show_song` endpoint.
